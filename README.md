# Skeptical, draft 2

Seven drafts of the Skeptical site in one app, one route each. Not deployed.

    npm install
    npm run dev

Then open http://localhost:5173. On a Mac you can also double-click `start.command`.

Stack: Vite, React 19, TypeScript, React Three Fiber + drei + postprocessing, GSAP (ScrollTrigger, SplitText, DrawSVG), Lenis, Tailwind 4, shadcn/ui.
